                                     Smart Recipe Book & Meal Planner
----------------------------------------------------------------------------------------------------------------------------

Project Overview :

The Smart Recipe Book & Meal Planner is a command-line based application developed using Core Python. The main purpose of this project is to help users manage recipes, plan meals, and generate shopping lists in a simple and organized way.
The application allows users to register and log in, maintain a collection of recipes, search recipes based on available ingredients, adjust ingredient quantities according to serving sizes, create meal plans, and generate shopping lists for missing ingredients. All data will be stored in text files, ensuring that information is saved even after the program is closed.
The project is designed to demonstrate the practical implementation of Core Python concepts such as lists, tuples, sets, dictionaries, strings, loops, conditional statements, functions, exception handling, and file handling.


----------------------------------------------------------------------------------------------------------------------------
Objectives :

Store and manage recipes efficiently.
Search recipes using available ingredients.
Create and manage weekly meal plans.
Generate shopping lists automatically.
Perform CRUD operations using file handling.
Demonstrate the use of Core Python concepts in a real-world application.
